A streaming-app roast with a sideways take: the "Are you still watching?" prompt as the one wellness check the narrator ever receives — and the only way to answer it is to find a remote that vanished two episodes back. Not a "too many subscriptions" or "nothing to watch" complaint; the gripe is that being checked on is also the moment you confront how far the remote has drifted into the couch. One line, standard-library Python.

## Run it

```sh
python3 main.py
```
